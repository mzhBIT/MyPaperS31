# DU4 三帧融合预热

仅在全屏稀疏 DU4、去重有效、基础流水线启用且预热数量正好为三张时启用。三张使用各自的转换表，旧画面和目标每个字节对只读取一次、目标桶编码只计算一次，同时累积三个输出驱动字；输出引脚排列仍由原 `permute_epd_output` 执行。密集全屏仍用旧函数，保留其每相独立的 unchanged/equal-idle 快捷处理，不改变行为。

保留原稀疏组筛选及三帧清零。外部内存总线让步保留，并按三个输出缩短组间让步间隔，避免增长突发占用时间。三张输出完全写完后才发布 ready，后续生产任务继续从原 next_unique=3 开始。波形、相映射、预热数量、电源等待与动画不变。

已有 4096 项表用于第一张；惰性申请额外两张 4096 项内部 RAM 表，总计新增 8 KiB 内部 RAM，不增加输出帧数量。分配失败、非全屏、不同预热数及动画路径回退到原单帧算法。

`MYPAPER_EPD_2D_DU4_TRIPLE_PRIME=0` 可关闭。刷新后的 `DU4 prep summary` 新增 `prime_fused=1`，对比 prime / prime_pixels / prime_clear；融合减少重复读取与循环，三帧输出写入量不变，收益以设备测试为准。

PC `tools/test_epd_du4_triple.cpp` 验证 327680 个 16 像素组的三个输出均与独立逐像素波形参考一致，覆盖所有旧/新字节组合、四种驱动值及随机转换表。设备测试需覆盖稀疏文字、密集图片、菜单局部刷新、周期 Quality 与动画，以及并行 USB 音频，确认画面、欠载与音频实时性不回退。
