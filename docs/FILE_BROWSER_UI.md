# 文件管理界面

采用 `read-pico-reader/main/apps/app_files.c` 的 684×1216 竖屏布局，来源为 2026 mindreset（Apache-2.0）。保留本项目 Activity、三语本地化、系统字体及文件打开逻辑。

- SD 根目录：状态栏、大标题、容量卡片、名称排序、目录列表、底部四栏导航。“文件”标题右侧的加号打开 Wi-Fi / 热点 / USB 二级浮层菜单；点击外部、再次点击加号或返回可关闭，浮层打开时不响应底层列表与翻页。
- 子目录：圆形返回键、目录名称与路径、双行列表，文件夹和文件图标、大小、右箭头及页码。路径区分割线依据实际字体行高下移，确保文字下方留白。
- 长按：保留列表背景，在 `(20,430,644,626)` 叠加圆角面板；显示名称、大小、路径，操作按钮和底部取消。删除确认复用同一面板。
- 文件图标直接提取原作 72×72 灰度 alpha 掩模，显示尺寸为 46px；导航和箭头沿用此前导入的原作 Lucide 图标。授权见 `docs/licenses/pico-shelf-icons.txt`。
- 目录列表展示非隐藏的普通文件和目录，不限制可打开格式；不支持的格式仍走现有提示页面。
- 点击打开；长按操作；上下或左右滑动翻页。底部导航可切换主页、书架和设置。名称排序可切换升降序，文件夹始终优先。
- 文件管理和书架的首页按钮使用 `ActivityManager::pop_to_root()`，清理中间 Activity 时不调用它们的 `on_show()`，只显示一次首页，避免逐层退栈造成中间页面闪现。普通返回仍逐层退出。
- 现有操作为重命名（含扩展名）、文件删除、图片设为阅读背景；尚未提供复制、移动和递归删除目录，不绘制无效按钮。
- 热点入口直接复用既有 AP 传输实现；USB 入口进入既有重启确认，不绕过确认或改变 SD 独占规则。原传输页面继续保留。
- 存储卡卡片只显示容量及已用/可用文字，不绘制占用进度条。
- 文件管理首页、子目录、操作面板、删除确认及重命名输入覆盖层统一使用 `epd_text` 刷新；不修改任何波形。输入覆盖层通过调用选项启用，其他应用的默认刷新不变。

绘制与触摸范围统一来自 `main/ui/FileBrowserLayout.h`；运行 `tools/test_file_browser_layout.cpp` 可检查列表、按钮和面板边界。图标可用 `python tools/import_pico_file_icons.py <原作工程目录>` 重新导入。新增 UI 字符串必须按 `SYSTEM_FONT.md` 检查内置 TTF 子集覆盖。

列表不再固定为 91px 行高：取文件名行高、详情行高及 32px 间距之和，最低 91px；每页行数按可用高度向下取整。首页目录卡片也按相同行高调整，标题、详情、图标和触摸范围共用布局结果，字号变大时自动减少每页条目数。

传输入口收纳后，根目录列表起点最低为 y=362，可用底边为 y=1025；实际起点由存储卡和“根目录＋排序”行的字体高度推算。存储卡标题与容量共用首行、使用量单独一行，卡片高度随字体增高；根目录行下方至少留 12px 再绘制列表边框。排序按钮宽度按本地化文字测量，高度随该行变化，触摸范围与绘制共用布局。空间按当前字体行高换算为可见条目数。浮层沿用 `epd_text`，USB 确认流程不变。
