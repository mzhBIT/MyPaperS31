# Pico Reader 书架移植

## 范围

仅替换书架页面。首页、文件管理、设置保留现有实现；底部四标签是书架的导航入口，不代表其他页面也完成了 Pico 风格迁移。

参考 `read-pico-reader-main/main/apps/app_book.c`、`main/ui/ui_kit.c`、`main/ui/ui_nav.c` 和原项目手册截图。独立入口为 `launch_bookshelf()`，布局及命中区域统一定义在 `main/ui/BookshelfLayout.h`。

## 风格与坐标

- 默认亚克力：3×3，每页9本；封面164×214，列起点54/259/464，行起点224/506/788。
- 深色书轨：沿用相同封面布局，书轨位于每排封面底部。
- 列表：每页4本，外卡片36,216 / 612×788，行高197，封面120×156；书名最多两行、下方阅读时长、进度及进度条。
- 亚克力板：20,360+282×row / 644×90；先快照再13权重采样模糊与着色，避免原地模糊污染后续像素；临时RGB565缓冲约113KiB，使用PSRAM并在绘制后释放。
- 页眉、分页箭头、底栏沿用原作684×1216坐标；未改波形。为保留灰阶，书架采用 `epd_quality`。

点右上角“管理”（英文 Style）选择三种风格。风格保存到NVS `bookshelf_ui/style`，恢复默认设置会清除此偏好。左右或上下滑动、底部箭头均可分页。导入入口进入现有书籍文件浏览器，打开书籍后加入现有阅读书架；没有另加扫描器或修改书籍文件。

## 与原作的有意差异

- 数据沿用现有最近阅读书架，已移除20本上限：初始预留32本记录，满后按64、128、256等翻倍扩容；读取、保存及重命名迁移均处理全部记录。排序仍为最近打开优先，不自动扫描全部书籍；不迁移原作的批量管理、收藏、作者数据库、封面弹跳动画。旧版本已淘汰的记录无法恢复，需要重新打开书籍加入。容量仍受可用内存及容器分配能力限制（本工程关闭 C++ 异常，未新增内存耗尽恢复机制）。
- 原作列表作者行使用本项目阅读时长替代，不伪造作者。阅读进度、退出保存以及各格式打开流程保持不变。
- UI字体仍采用用户选择的系统字体；字号和布局采用原作区域规格，因此字体轮廓不会与原作 Noto Sans 完全相同。设置中的全局字号不缩放本页固定设计坐标。
- 开发板缺少可靠电量测量，状态栏仅保留电池轮廓图标，不显示电量百分比（包括 `--%` 占位）；Wi-Fi 图标移至电池左侧。不展示虚构电量或蓝牙状态。时间遵循现有时间基准。

## 字体及资源

文字按实际字形边界居中，灰底抗锯齿使用背景色混合，避免白色光晕。系统字体使用12个按字号分组的LRU缓存，按需分配字形池，不与阅读器共享字体状态；每个主字形池上限128KiB PSRAM，完整字体回退按需加载。

SD FAT挂载允许32个同时打开文件：12组UI缓存最多24个SD字体句柄，其余留给阅读器、ZIP、封面等。淘汰字号缓存会关闭该组所有字体；切换字体/字号立即释放旧组。此限制需要重启重新挂载后生效。

书架超宽字号适配使用宽度比例估算和最多3次测量，不再逐像素递减字号；保留1px估算余量。适配结果采用32项有界缓存，按完整文字、初始字号、可用宽度及系统字体代次匹配，跨书架 Activity 重建保留；返回相同页面可直接复用，语言文字/字体/字号变化时不会误用旧结果。该缓存不持有字体文件句柄。首次遇到新字号仍需初始化字体；不承诺完全消除冷加载。

7个Lucide原始72×72/4bpp覆盖率图标从原项目提取，固件只依赖已生成的 `main/ui/pico_shelf_icons.h`，无需外部项目参与构建。

更新图标：`python tools/import_pico_shelf_assets.py <read-pico-reader目录>`。

许可证见 `docs/licenses/pico-shelf-icons.txt`（ISC）及 `docs/licenses/pico-reader-Apache-2.0.txt`。布局及亚克力算法参考原项目，保留2026 mindreset署名。

## 字号缩放

普通 UI 文字复刻原作规则：基础字号先加 2，结果小于 46 时跟随系统缩放，否则固定。现有系统字号 24..48px 对应 100%..200%（比例=系统字号/24）；默认 28px 约 117%，接近原作默认 120%，不新增独立设置。默认底部标签 17→22px、按钮 20→26px、弹窗 28→35px，大标题 52→54px。顶部时间/电量固定 28px；列表书名/阅读时间/进度保持固定 27/21/19px，FreeType 直接按 EM 像素尺寸渲染，无需照搬 stb 的行高换算。无封面书名跟随普通 UI 缩放，并按封面高度限制行数。按钮、分页和底栏文字超宽时缩小至区域内，测量、居中与绘制使用同一最终字号。此节取代前文“全局字号不缩放本页”的旧说明。

## 区域刷新

书架主体使用 `epd_hd`。初次进入及从其他页面返回时整页绘制；翻页、键盘焦点和切换风格仅绘制内容及分页区（逻辑坐标 y=197..1095）；打开风格弹窗仅刷新 90,370 / 504×432，关闭时重绘内容区以恢复亚克力背景。

状态栏每分钟统一使用 `epd_text` 更新一次顶部 684×72，时间、Wi-Fi 和电池图标同步重绘，不单独响应 Wi-Fi 变化。时钟分钟变化触发更新；时钟尚未同步时也通过单调计时保证约 60 秒更新一次。状态栏更新完成后恢复原刷新模式；不修改任何波形。

2D 驱动原先无条件将 Quality/HD 扩成全屏，现改为尊重请求区域。GC16 双像素查表及环形生产者均传递区域参数，区域外（含边界同组像素）输出中性码；物理状态提交也只提交该区域。仅物理状态未知（包括刷新失败后的恢复）仍强制全屏 Quality。全屏快速路径保持不变。

局部刷新仍扫描完整面板的全部相，主要减少区域外闪烁及区域内驱动数据生成工作，不承诺扫描时间按面积缩短。实机检查：等到分钟变化，确认顶部状态栏统一更新、书架正文不刷新；Wi-Fi 变化不额外触发刷新；翻页确认页眉与底栏不闪；打开/关闭风格弹窗、切换三种风格及返回书架；首次恢复全屏闪动是预期保护行为。`batch begin` 的 area 使用物理坐标，竖屏下与上述逻辑坐标有旋转映射。

## 验证

### 密集封面 Quality 欠载保护

实机出现 40 张独立 GC16 帧、扫描至 phase=44 时 unique=37 未就绪；首批生成约 286ms，后续 worker 约 540ms。对于超过 32 张独立帧的 GC16 批次，预热填满现有环形槽（当前 20 帧），其他 GC16 和 HD 保留原预热设置，不增加缓存容量、不修改波形。以约 20..23ms/帧估算，将剩余生产量从 26 帧降至 20 帧，为约 530ms 扫描及上电窗口增加裕量；这是针对观测负载的保守策略，仍需密集封面、多次翻页和并行音频实测。局部帧内部完整 16 像素组使用无逐像素边界判断的路径，仅首尾组处理裁剪。失败批次保持物理状态无效，下一次强制全屏 Quality 恢复。

- `tools/subset_system_font.py --check`：检查新增简繁文字的固件字体覆盖。
