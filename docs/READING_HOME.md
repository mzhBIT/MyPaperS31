# 独立阅读首页

## 入口与导航

当前多应用图标主页保持不变。书架、文件管理底部的“首页”进入独立阅读首页。阅读首页底栏可进入书架、文件管理、设置；返回键返回系统主页。

重复进入阅读首页复用现有 Activity，并一次移除它上方的页面，不重绘中间页面。首次从没有阅读首页的分支进入时替换系统主页上方的分支，不替换系统主页本身。

阅读首页、书架和文件页共用 `ShelfStatusBar.h` 绘制顶部时间、Wi-Fi和电池，
以及 `ReadingNavigation.h` 绘制底栏；`ReadingNavigationLayout.h` 同时定义绘制和触摸命中范围。
四个标签统一为“首页／书架／文件／设置”（沿用三语本地化）。底栏固定在y=1096..1215，
高度120px，图标44px且中心y=1141，选中短条56×5px；标签字体统一跟随系统字号并按实际墨迹高度定位。
各页只传入选中标签，不再分别维护图标缩放、文字纵坐标或选中标记。

## 原作布局、字体与资源

参考 `read-pico-reader/main/apps/app_dashboard.c`，2026 mindreset，Apache-2.0。684×1216 竖屏：

- 状态栏中心 y=40，大标题位于 36,90，分割线 y=195。
- 续读区域 y=216..618；封面 36,292 / 172×250，右侧书名、作者、已读百分比、进度条与继续阅读入口。
- 七天统计分割线 y=619，标题中心 y=643；图表卡片 36,698 / 612×334，基线 y=947，七根圆角柱每隔 80px 绘制，星期中心 y=977。
- 四栏导航 y=1096..1215，原作 Lucide 72px 灰度 alpha 图标显示为 44px，首页选中短条宽 56px。

普通文字沿用原作 `(基础字号+2)×系统缩放` 的规则，通过现有 24..48px 系统字号映射 100..200% 缩放。加 2 后达到 46px 的大字不缩放；首页大标题为 54px。续读书名使用原作专门标题规则，固定 40px、按可用宽度截短，不随系统缩放。状态栏时间固定 28px。字体使用用户选择的系统字体与现有缺字回退，不另外打开阅读正文字体。长文本在有限控件内适配宽度；大字号时进度条与继续阅读文字依据行高调整，避免重叠。

保持原作常规字号坐标；大字号/特殊字体实际字形超出原布局时，依据 `SystemFont::ink_height()` 调整统计标题、图表卡片和首条网格线位置，柱形可用高度相应缩短，避免标题穿过分割线。进度区也使用实际墨迹高度而非字体行距，以保持常规字号更接近原作位置。

直接复用 `main/ui/pico_shelf_icons.h` 的原作图标，不重新手绘。授权见 `docs/licenses/pico-shelf-icons.txt`。主体 `epd_hd`；每分钟顶部状态栏使用 `epd_text` 统一更新。不显示电量百分比；S31按真实采样填充电池，未知时显示短横线，P4沿用轮廓占位。Wi-Fi 位于电池图标左侧，位置及电池外框与书架、文件页一致。

封面优先读取现有最终尺寸 BIN/JPEG 流程，新增首页尺寸 172×250 的缓存文件由现有缓存接口按需生成；页面保留约 21.5KiB PSRAM 4bpp 封面缓存，切换标签或阅读返回不重复解码。缓存由封面路径、大小、修改时间校验。

续读优先展示最近打开的有效本地阅读记录。EPUB 的书名/作者读取容器及限长 OPF，不加载章节和目录；同文件重复进入复用元数据。其他格式沿用现有书名，未提供作者时留空。没有阅读记录时显示原作式引导，不构造示例书籍。“查看详情”和续读区域与原作一样是同一个打开书籍入口，不新增虚构的详情页面。

## 七天真实统计

- 计时依然使用 `esp_timer_get_time()` 单调时钟，暂停/隐藏不计时，不在翻页、循环或后台预处理时写文件。
- 系统日期有效的阅读段按开始时的全局时间基准归属日期（默认北京时间），跨午夜按实际持续时间拆分；校时不改变已累计的单调时长。
- 时间未同步的阅读段保留每本书总时长，但不猜测日期、不倒填七天统计。校时后新的有效日期阅读段才计入图表。
- 保留最近 30 个日期的微秒累计，在退出阅读的 `BookReadingTimer::finish()` 中与原累计时长一起保存。七天图表以秒读出，显示累计/日均到分钟或小时；微秒精度避免多次短暂阅读截断丢失。
- 存储 `/sdcard/.reader/reading_time/days.bin`：RDD1 标记、最后日期、30 个微秒计数和 FNV-1a 校验；临时文件与 `.bak` 处理沿用现有进度文件替换策略。此文件独立于每本书的 `.time`，不会改动旧记录格式。
- 旧累计时长没有日期信息，不能恢复历史分布。升级后的七天图表从新会话开始积累；有有效日期但暂无记录时显示零统计，日期无效时显示日期设置提示。
- 每日归属使用会话开始时的时间基准；改变时区不会重新解释旧日期计数。

## 验证

底部首页、书架、文件、设置标签切换时替换系统主页之上的应用分支，销毁旧标签页面并保留系统主页；不再每次切换都 push 新页面。普通打开书籍、文件操作及独立应用入口仍保持原有导航。原生控制中心／ActivityManager 回归包含连续 50 次标签分支替换，验证页面栈始终只有根页面和当前标签，旧页面析构且中途不重绘根页面。

`tools/test_reading_days.cpp` 检查跨午夜、暂停累加、日期淘汰、负偏移、统计柱和大字号进度区边界。更新 UI 文案后必须执行 `tools/subset_system_font.py --check`，必要时生成并提交内置字体子集。

已通过跨午夜/统计布局与 Activity 导航的 PC 测试、相关源文件定向编译和 P4 完整构建（`build-p4/MyPaperP4.bin`）。内置字体子集新增字符后已重新生成并检查，无缺字。

实机待验证：从书架/文件管理进入、底栏切换、续读打开、返回不闪中间页面；系统字号 24/28/36/48、三语言、不同字体；12/24 小时显示、校时与午夜；阅读后退出新增统计，页面停留或暂停不增加时长。尚未烧录验证。
