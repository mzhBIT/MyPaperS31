# 应用顶部状态栏统一

首批迁移传输入口、Wi-Fi／热点传输、音乐、收音机；USB U 盘模式页同步顶部绘制样式。其他应用保持当前布局，后续逐项迁移。

第二批迁移新闻应用及其源列表、新闻列表、正文、Bing 壁纸、加载提示和 RSS 背景／字体选择页；详情见 `RSS_FEED_MANAGEMENT.md`。订阅源管理新增的键盘输入页也通过可选配置接入统一状态栏，不改变其他调用者的键盘页眉。

共用 `ui/AppStatusBar.h`：直接复用主页 `ShelfStatusBar` 的时间、Wi-Fi 信号强度及电池图标。72px 高度、白底，时间左侧起点 36px，垂直中心 40px；Wi-Fi 和电池的坐标、尺寸、灰阶及填充逻辑与主页一致。应用标题固定 28px、屏幕居中，并按实际时间文字宽度及右侧图标预留区裁剪，长标题按 UTF-8 字符边界省略。

传输入口不再保留覆盖时间区域的隐形返回点击区，继续支持返回手势和按键。音乐、收音机显示固定应用标题，歌曲／列表／电台名保留在下面；音频输出按钮移动到第二行右侧，按钮文字使用 24px。按钮绘制及触摸使用同一个 `AppStatusBarLayout`，状态栏区域不触发输出切换或隐形返回。

普通 Activity 状态栏按分钟／时间文本变化刷新，Wi-Fi 开关状态变化也会更新；刷新时采用 Text 模式，仅提交顶部 72px，再恢复应用刷新模式。屏幕忙或正在触摸时延后，音乐冻结显示时暂停自动状态栏刷新。Wi-Fi 传输有活动请求时不插入自动状态栏刷新。USB 专用模式沿用状态变化驱动的整页绘制，不增加后台状态栏刷新任务。

新文案沿用现有本地化字符串，没有新增字形。原生 `tools/test_app_status_bar_layout.cpp` 验证长时间文本、两种宽度、标题避让及半开触摸边界。设备上待验证 12／24 小时、简繁英文、系统字号 24–48、音乐播放与传输时刷新和输出按钮操作。
