# 提前统计下一页的灰度转换

## 接入与用途

TXT 和 EpubReaderActivity 的独立整页预绘制完成后，调用面板可选接口 `preparePhysicalGrayscale4Stats`。重排阅读器涵盖 EPUB、微信读书及使用相同渲染路径的格式；横排、竖排和已接入整页预绘制的单图片页共用该入口。未预绘制的页面仍现场统计。

公共引擎支持 DU4/Text、GC16/Quality、HD 和 DU/A2 的转换类型统计。DU/A2 的缓存目标先按实际刷新规则二值化。DU4 还提前记录有驱动的 16 像素组，省去现场重复筛选。不是提前生成驱动帧，本次不改变 3 张基础帧或动画预热帧的生成时机。

## 数据归属与失配保护

单份缓存由 Panel_EPD_2D 持有，包含目标整页副本、256 项转换标记及可选 DU4 组索引。1216×684 面板目标副本 415872 字节、组索引最多 103968 字节，合计约 508 KiB PSRAM；标记与元数据少量内部内存。惰性申请、分配失败回退，不借用阅读器可能释放的 Buffer。

准备与整个物理刷新批次共用互斥锁。准备仅在空闲时非阻塞尝试获取；刷新任务在收到更新后持锁，所有失败/continue 路径由 RAII 释放。准备不会向显示队列提交更新，不改 draw/target/physical Buffer。

每个刷新批次递增物理画面代数，包括菜单、局部刷新及失败批次。消费缓存必须同时满足：

1. 物理状态已知、代数与准备时一致。
2. 内部物理旋转（包含面板 offset_rotation）、波形类型及所选波形表一致。接口参数仍是逻辑旋转，仅用于验证预绘制 Buffer；缓存键与刷新队列均使用内部旋转，不能混用。
3. 实际更新是整页。
4. 实际目标与缓存目标逐字节完全一致（包含页眉、页脚、单个像素变化）。

使用现场目标快照核对，不依赖指针身份、不使用可能碰撞的哈希。命中也有整页比较与组索引复制开销，因此现场 stats 不会完全归零。菜单、跳页、周期强制 Quality、图片强制 Quality、模式变更等失配后自动现场统计，画面质量逻辑保持原样。

预绘制完成后先补画目标页对应页眉，再统计：EPUB 使用目标 spine 编号，TXT 使用目标页起始偏移的百分比。前台仍可按原逻辑重画相同页眉；不能对仅有正文的 Buffer 做整页统计后期待完全相同。

## 验证

PC 测试 `tools/test_epd_prepared_stats.cpp` 检查代数、旋转、模式、波形表、区域、物理状态以及整页每个字节变化均拒绝缓存。

设备日志：

```text
prefetch statistics ready: type=... transitions=... groups=... time=... us
dispatch summary (after refresh): ... stats_cache=1
```

`stats_cache=1` 表示命中；0 表示现场统计或该路径未使用去重统计。对比 `DU4 prep summary` 的 stats 耗时，prime 应基本不变。需要设备回归连续翻页、返回上一页、打开/关闭菜单、改刷新模式、强制 Quality、动画及图片页，确认所有失配都能安全回退。

刷新后的 `stats_miss`：0 命中，1 无有效缓存，2 物理状态未知，3 非整页，4 无目标副本，5 物理代数变化，6 旋转变化，7 模式变化，8 波形变化，9 目标内容不同，10 未走统计缓存路径。仅刷新后输出，不在扫描关键路径打印。
