# 全局下拉控制中心

电量下方显示“剩余 PSRAM/SRAM”，数值格式为 `12345KB/123KB`，以 KB（1024 字节）为单位。SRAM 使用 `MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT` 的可分配内部空闲堆，不包含 PSRAM，也不表示全部物理 SRAM。打开时读取一次，面板空闲且未触摸时每秒检查，任一整数 KB 变化后一起局部刷新；数值包含控制中心快照占用后的实际空闲量。大字号时按实际文字宽度缩小这一行，避免标题与数值重叠。移除“点击空白处关闭”提示，面板外点击关闭行为保留。

从屏幕顶部 48px 区域向下滑动打开；向上滑动或点击面板外区域关闭。S31 右上角为矢量电源按钮，点击请求真正关机；P4 尚未实现硬件断电通路，右上角保留关闭按钮。顶部普通点击和从正文开始的滑动继续交给应用。识别成功的下拉手势会被全局消费，避免同时触发翻页。刷新忙时等待空闲再打开；期间切换应用则取消请求。

S31 软件关机复用电源键长按的 `standby::request_shutdown()` 安全流程，不用待机模拟关机。等待当前刷新结束后先关闭浮层、保存亮度/色温并恢复底层画面，再记录关机请求，避免浮层存在或页面 generation 变化取消关机。随后等待安全 I/O 边界，关闭网络、前光，退出应用保存阅读进度和时长，再通过电源锁存电路断电。底层已有的忙超时、保存失败及断电失败处理保持一致。

首版提供亮度连续滑条及加减按钮，复用设置中的前光接口和 NVS 配置。拖动实时预览 PWM，松手保存，墨水屏仅在空闲时限频局部刷新。色温和亮度上限沿用原配置。打开控制中心修改亮度后返回亮度设置，数值会同步。

`ActivityManager` 提供独立 modal overlay 槽位，不调用底层应用的 `on_hide/on_show`，不会因下拉控制中心停止文件传输、重新打开书籍或重建播放器。打开期间只运行浮层的 UI loop，底层后台工作继续执行。快照约 416KB，分配在 PSRAM；分配失败时不覆盖原画面。关闭后恢复原始 4bpp 绘图缓冲，仅对被覆盖区域使用 epd_hd 刷新，保留原页面灰阶。

切换应用、回到根页面、关机时管理器统一释放浮层。来电优先关闭浮层；S31 电源键也先关闭浮层，再执行原有待机或关机流程。浮层拖动不向应用透传触摸。界面支持英文、简体和繁体；新增字符串后执行字体子集覆盖检查，缺字时重新生成子集。

后续音量、Wi-Fi、蓝牙控件在 `ui/ControlCenter.cpp` 增加独立控制行，分别调用对应系统服务；不在浮层中复制驱动初始化或另存配置。当前不绘制未实现的开关。若控制行增多，扩展布局与触摸命中范围，并调整遮挡区域的快照恢复刷新高度。

验证：S31 完整构建；P4 相关文件编译检查；`tools/test_control_center.py` 对实际管理器和手势入口做原生回归，覆盖浮层打开/关闭不触发应用生命周期、根页面恢复、应用切换释放、下拉边界及重复打开拦截。设备上需验证阅读/播放/传输期间打开与关闭、拖动连续性、亮度持久化和灰阶恢复。
