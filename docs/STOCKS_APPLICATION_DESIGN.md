# 股票查看（首版）

## 数据源与边界

采用腾讯网页行情入口 `https://qt.gtimg.cn/q=sh600519,usAAPL`，A股与美股批量请求，无需 API Key。已实测沪深股票及 AAPL/MSFT 返回报价。对应提供方页面：https://gu.qq.com/usAAPL.OQ 。这是网页接口，并非有稳定性/SLA承诺的正式开放 API；只用于个人低频查看，不作为交易依据，也不代表取得再分发授权。接口变更时需要维护适配器。

替代来源：Finnhub（https://finnhub.io/docs/api/quote）、Twelve Data（https://twelvedata.com/docs）；需要账户密钥，市场覆盖、时效和授权以其套餐为准。首版不引入付费依赖。

## 实现

- 主页第二页新增 Stocks/股票，图标从原始 SVG 导出模板提取 Regular-S 实际图形，150×150、1bpp，与系统图标外框和选中态一致。
- 自选最多20只，NVS `stocks/watchlist` 保存逗号分隔代码。默认上证指数、深证成指、贵州茅台、苹果、微软。
- 支持显式 `sh600519`、`sz000001`、`bj...`、`usAAPL`；普通六位代码推断交易所，美股简称补 `us`。指数推荐显式前缀，避免000001歧义。
- 每页5只，上下滑动翻页；点击详情，长按删除确认；添加使用已有浮层键盘。
- 展示最新价、涨跌额/幅、昨收、开盘、最高最低、币种、提供方原始报价时间。美股时间不擅自解释为北京时间。报价可能延迟；不实现自动实时轮询、K线和交易。
- HTTPS证书校验，单次响应上限32KiB，批量拉取所有自选。正常手动刷新间隔10秒；添加代码允许即时补取。
- core0低优先级任务、12KiB内部RAM栈执行联网和解析，不触碰显示缓冲；主任务消费已完成结果后绘制。任务退出后释放栈。EPD刷新核心/波形不改动。
- 联网任务不能使用PSRAM栈：`wifi_setting_connect_saved()` 会读取NVS凭据，Wi-Fi初始化也可能访问Flash；Flash操作临时关闭缓存时PSRAM栈不可访问，会触发 `esp_task_stack_is_sane_cache_disabled()` 断言。仅把凭据提前读取仍不足以保证整个Wi-Fi初始化链路安全，因此任务栈明确限定内部RAM；不把全部行情数据强制放入内部RAM。
- 请求失败保留已有行情；部分缺失保留旧值与旧来源时间。删除与NVS写入不与请求并行。
- 退出时若有请求，异步等待结束后返回，主循环不阻塞；结束后按系统常开/省电网络策略释放连接。联网等待上限15秒，HTTP各次阻塞读等待上限8秒。
- 解析 `~` 分隔字段，股票名称通过项目已有 GBK 解码转UTF-8；无效/空报价显示 `--`，不伪造为0价。三语言标签复用UiLocale。

## 验证

PC实测腾讯批量返回沪深/美股数据；固件构建后设备验证添加、删除、NVS恢复、上下滑动、详情、刷新失败保留旧行情、Wi-Fi/4G以及三语言。北交所代码只接受格式，具体覆盖以服务端实际返回为准。
