# 书架封面缓存

书架优先读取最终尺寸的无压缩4bpp灰度BIN；缺失、源文件变化或校验失败时，沿用JPEG缩略图/原图绘制流程，并在绘制边框与书轨之前保存当前封面像素。写缓存失败不影响显示。没有图片封面的书名占位不写入BIN。

首次制作 `cover_thumb_v1.jpg` 时，额外生成两种BIN。BIN绑定保留的JPEG路径，避免原始封面提取文件被删除后失效。

| 样式 | 尺寸 | 像素字节数 |
| --- | --- | --- |
| 亚克力、深色书轨 | 164×214 | 17,548 |
| 列表 | 120×156 | 9,360 |

路径为 `<封面图片路径>.shelf_<宽>x<高>_v1.bin`，与JPEG并存。只生成派生缓存，不修改源文件。旧缓存首次进入对应书架样式时自动补齐；后续进入无需重新解码和缩放。

文件头32字节，8个小端uint32字段：magic（0x34435643）、版本（1）、宽、高、源文件字节数、源mtime、像素字节数、像素FNV-1a校验值。像素逐行存放，每字节左高右低两个灰阶，0黑15白。读取校验头、文件长度、源信息和像素校验值后才写入屏幕缓冲。临时文件完整关闭后才替换派生缓存。

2D面板使用原生4bpp矩形导入，直接复制灰阶，不展开RGB、不再次量化；脏区仅覆盖导入矩形，保留局部刷新。首次生成使用独立内存面板，不触发硬件扫描。缓存读取需要暂存一张封面像素，之后释放，无常驻整书架像素缓存。

测试：主机编译运行 `tools/test_cover_bitmap.cpp`。真机需对比首次补生成和第二次打开的 `BOOKSHELF draw timing` 中cover耗时，并检查两种尺寸、旋转、翻页区域、损坏BIN回退以及源图更新重建。
