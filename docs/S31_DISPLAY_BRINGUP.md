# MyPaperS31 显示与触摸验证

日期：2026-10-01。状态：代码编译通过，显示硬件尚待实机验证。

## 本轮范围

启动骨架已经实机验证。本轮实现依赖于屏幕的第一层交互应用，不是完整主页或阅读器：

- M5GFX 新增 MyPaperS31 初始化分支，固定板型，不试探其他型号引脚。
- 独立 `Bus_EPD_S31`：LCD RGB 单次扫描 + RMT CKV，8 位数据线。
- TCA9555 控制屏幕供电、TPS65185 控制线和触摸复位。
- TPS65185 的电源良好检查、关机放电等待；扫描失败后禁止继续复用在途 framebuffer，需重启。
- 复用现有 GC16/DU4 等波形数据与 4bpp 绘图接口。
- FT6336U 使用 FT5x06 协议，IDF 6.1 I2C Master 驱动，触摸与 EPD 刷新不同时访问板级 I2C。
- 4 个灰阶测试页面，点击切换，打印触摸坐标。

没有初始化 SD、Wi-Fi、USB、音频、前光、RTC，也没有接入原 ActivityManager。无 PSRAM 或显示初始化失败时停止界面启动，不自动重启或清空 NVS。

## 扫描与内存

物理屏幕 1216×684，逻辑竖屏 684×1216，offset_rotation=3。8 位总线每行传输 304 字节，每相 207936 字节。

PCLK=20 MHz。304 字节需要 15.2 μs；保留 LE 6 个时钟和前沿 16 个时钟后至少 16.3 μs。本轮取行周期 17 μs、CKV 高 16.3 μs。P4 的 16 μs 设置没有改变。S31 默认 VCOM=1200 mV，来自参考板配置；应根据实际屏幕标定，不能仅据相同型号保证最佳残影表现。

RGB 单次发送缓存约 203 KiB，额外于 EPD 的绘图/目标/物理缓存。为减少实机验证变量，S31 暂关闭 GC16/DU4 生产流水线，完整预计算并去重相位帧；最坏临时占用约 9.52 MiB PSRAM。阶段 2 不是性能最终配置。

8 位后端不应用 P4 的相邻字节交换。灰阶测试需核实像素顺序；不能用编译成功替代验证 CKV、SPV、STH、LE 的相位关系。RGB 与 RMT 启动包含软件衔接，若行错位、闪烁或无法刷新，应采集逻辑分析仪数据，再调整独立后端，不改波形来掩盖扫描问题。

## 验证步骤

使用现有 S31 构建/烧录任务，构建输出是 `build-s31/MyPaperS31.bin`。本轮没有代为烧录。

1. 启动应出现 `EPD_S31: 8-bit RGB ready` 与 `S31_UI: pattern=0 queued`，随后显示标题和 16 灰阶条。
2. 每点击一次依次显示：黑上白下 → 全幅灰阶条 → 白上黑下 → 初始页。
3. 核实灰阶从黑到白顺序、文字方向、无横向错位/漏行；对比黑起点与白起点的残影。
4. 核实触摸坐标与逻辑竖屏一致，持续点击不出现 TPS 超时、scan failed 或看门狗。
5. 冷启动和连续切换均测试。发生扫描失败请保留完整启动日志；本后端会停止继续给屏幕施加电压，不宣称更新成功。

通过后继续阶段 3：SD 挂载、Board 显示/输入接口统一、原主页与本地阅读器；再接入原生 Wi-Fi。P4 完整应用仍使用 IDF 5.3.5。
