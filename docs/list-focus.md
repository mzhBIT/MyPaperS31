# 公共列表焦点

`main/ui/ListFocus.h` 是列表导航焦点的统一样式入口，默认黑色竖条宽 5 px、距行左边 2 px、上下留白 16 px、与文字间距 12 px。短行留白自动缩小为不超过行高的四分之一。

- `list_focus::draw(gfx, left, top, row_height, focused)`：在行清屏之后绘制焦点。
- `list_focus::text_inset()`：相对于行左边的文字起点，随样式参数同步变化。
- `list_focus::geometry()`：纯几何计算，可在 PC 上测试。

调用方负责擦除旧行/页面；组件不会擦除未选中行，避免覆盖缩略图、分割线或业务状态。修改样式只需修改公共 `style`，无 NVS 存储。

已接入：系统设置及网络/语言/日期/应用设置、Wi-Fi 扫描、DeepSeek/地图设置、EPD 测试菜单、传输菜单、文件管理器、字体/背景/铃声/离线地图包/DeepSeek 图片选择、DeepSeek 会话、阅读设置及章节目录、音乐歌曲和电台列表。

音乐与电台右侧的小播放三角标记表示当前播放项，左侧竖条表示键盘/触摸焦点，两者独立。语言当前值标记等业务状态保持原逻辑。

主页图标、键盘、计算器、确认按钮、标签页、地图定位点以及没有导航焦点的列表不纳入本组件。

验证：`tools/test_list_focus.cpp` 检查 1..300 px 行高的几何范围、非焦点不绘制、默认行高与文字留白。设备上应检查长文件名截断、焦点移出/返回、播放项与焦点不同时的两个独立标记。
