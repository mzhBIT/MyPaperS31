# RSS 状态栏与订阅源管理

新闻应用的订阅源列表、新闻列表、加载提示、正文、Bing 壁纸页以及 RSS 配置下的背景／封面／字体选择页统一使用 `AppStatusBar`。正文仍尊重隐藏页眉设置；打开阅读设置浮层时显示统一状态栏，字体预览继续保留在浮层内部。普通正文和图片为可见的 72px 状态栏预留空间，预绘制与触摸命中使用同一高度。非 RSS 阅读器的背景、字体页面布局不变。

## 操作

- 源列表右下角“+”：先输入订阅名称，提交后再输入 HTTP／HTTPS 地址；两个输入都完成后才保存，任一步返回取消均不添加半条记录。
- 长按已有源：修改名称、修改订阅地址、删除或取消。删除需要再次确认，默认焦点为取消。
- 输入使用现有全局键盘及光标移动；名称支持中文，地址默认英文。名称最多 255 字节、地址最多 2048 字节。空名称、配置分隔符／控制字符、基本 URL 格式错误和重复 URL 会提示错误并留在输入框内。
- 源列表按键 EXTRA 可以新增；长按菜单支持上下／确认／返回按键。所有新提示支持简体、繁体和英文。

## 存储

继续使用 `/sdcard/rss.txt`，每行 `名称|地址`，兼容注释、UTF-8 BOM、CRLF 和旧的纯 URL 行。新功能只管理订阅源，不自动验证服务器返回是否为可解析的 RSS，也不保证源服务器可访问。

只有配置文件和备份都不存在时使用内置默认源。删除全部订阅后会保存一个仅有注释的文件；再次进入或重启保持空列表，不恢复默认源。

保存先写 `.tmp`，检查写入、flush 和 close，旧文件改为 `.bak` 后再替换正式文件。替换失败尝试还原备份；正式文件缺失时读取 `.bak` 恢复。保存成功后才更新内存列表，正常写入失败不会丢弃原内存配置。此机制不能代替 FAT／SD 卡自身的断电一致性保证。

`tools/tests/rss_feed_store_test.cpp` 使用实际文件操作验证增删改、空配置、UTF-8、旧格式、备份恢复、写入失败与输入校验。设备上仍需验证两步键盘连续切换、长按操作、删除确认、滚动长列表后“+”命中，以及修改地址后的实际下载。
