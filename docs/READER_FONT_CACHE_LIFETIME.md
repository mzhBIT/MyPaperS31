# 正文字体缓存生命周期

TXT、重排阅读器（含 EPUB、微信读书等）及 RSS 阅读页面销毁时调用 `TextRenderer::releaseFontStreamCache()`，释放 SD 字体文件读取窗口，保留字体实例及已渲染字形。暂时打开菜单、控制中心、进入待机不触发此释放。

以 64 个 16 KiB 窗口配置为例，可回收 1 MiB；实际回收量以已分配窗口为准。内置字体和 BIN 字体不使用这套 TTF 流窗口，此调用不做处理。文件描述符仍随字体实例保留，切换字体或完整关闭渲染器时释放。

释放会清空窗口指针、范围和 LRU 状态，重复调用安全。下一次有效字体读取时按原窗口数量重新分配；内存不足时允许减少窗口或直接读取文件，避免因缓存重建失败而无法显示新字符。字形池和已缓存字形保持不变；更换字体或字号仍沿用原有重置逻辑。

`tools/test_font_stream_cache.py` 提取实际释放／恢复函数做原生生命周期验证，覆盖无文件字体、重复释放、恢复、部分分配失败及完全分配失败。

系统 UI 的 `ReaderTextStyle::share_font_stream` 单独开启：同一个 SD 字体的多个字号共享读取上下文（文件、窗口、LRU），每个 FreeType face 仍使用自己的 FT_Stream 对象。正文默认独立，退出正文释放缓存不会清除系统 UI 的共享缓存。注册表不额外持有引用，最后一个 UI face 关闭时释放缓存并移除注册项。同一路径但大小／修改时间不同不会复用旧上下文。

共享生命周期测试还验证跨 stream 命中、单个 face 关闭后继续读取、共享缓存释放后恢复、正文独立性及创建失败无残留。
