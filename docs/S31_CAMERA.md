# S31 摄像头与可选硬件

## 使用入口

正常开机时检测 GC2145，确认芯片 ID 为 `0x2145` 后才在主系统主页第二页显示「摄像头」；未检测到则隐藏入口，菜单和触摸区域同步调整，不保留空图标。每次重新开机重新检测，当前不做运行期间的热插拔扫描。

进入后默认自动预览；点击「拍照」会关闭自动预览、重新获取一张画面并保存到 SD 卡，然后显示保存结果。自动预览不写文件，不录制视频。

照片目录为 `/sdcard/images/camera/`，不存在时自动创建。保存为 **640×480 彩色 baseline JPEG，质量 90**；屏幕上的 4bpp 灰度图仅用于预览，文件直接使用同一张原始 RGB565 彩色数据编码，不会把屏幕灰度截图当作照片。

文件名示例：`IMG_20261107_153000_0001.jpg`，使用系统设置的时区。连续拍照遇到重名时递增末尾序号；系统时间无效时改用 `IMG_UNTIMED_XXXXXXXX_0001.jpg`。已有照片和残留临时文件都不会被复用。

拍照请求在当前预览任务完成后执行，保存期间不重复排队。后台按行转换 RGB565 到 RGB888 并软件编码 JPEG，不增加整张 RGB888 缓冲、不占用硬件 JPEG 编码器；编码和 SD 写入不持有 LCD_CAM 互斥锁。文件先写入 `.jpg.tmp`，完成编码、同步并关闭后才重命名为 `.jpg`。写盘失败或退出取消会清除本次临时文件，不显示保存成功；已有预览可继续查看。突然断电可能留下 `.tmp`，可在文件管理中删除。

保存成功时页面显示照片目录和文件名。可从文件管理进入 `images/camera` 打开照片，或通过文件传输导出。

GC2145 输出 640×480、RGB565 大端数据，使用官方 VGA 寄存器表、20 MHz MCLK，传感器标称 15 fps。墨水屏不跟随传感器帧率：自动预览按 1500 ms 间隔调度，等待上一轮采集、刷屏及触摸处理完成后才发起下一轮，不累积待显示帧。首次页面使用 quality，后续画面使用 hd。实际可见更新间隔还取决于采集和刷新耗时。

## 硬件与资源

| 信号 | S31 引脚 |
| --- | --- |
| D0–D7 | GPIO46–53 |
| PCLK / MCLK | GPIO54 / GPIO55 |
| VSYNC / HREF | GPIO56 / GPIO57 |
| SCCB（I²C） | 共享 In_I2C，地址 0x3c |
| 电源 / 复位 | TCA P0.5 / P1.2，与屏幕、触摸、基带存在共享 |

使用 ESP-IDF 6.1 的 DVP 摄像头驱动，MCLK 来自摄像头外设，不占用前光 LEDC 通道。`CameraS31.cpp` 只读检查共享电源，不切断 P0.5，不拉低 P1.2；传感器通过寄存器软复位初始化，避免重置触摸和 4G。

摄像头与 EPD 的 LCD 子模块共用 LCD_CAM。`EpdPeripheralGuard.hpp` 提供同一把互斥锁，EPD 在波形准备前获取，摄像头在探测、配置、采集和清理期间获取；持锁时不等待屏幕刷新。采集 DMA 完全停止后才允许下一轮 EPD 工作。

开机探测在显示/共享 I²C 初始化后、主页创建前执行，与 EPD 使用同一把互斥锁。暂时提供 20 MHz MCLK，选择寄存器 bank 0 并读取 PID，最多尝试三次；不写 VGA 初始化表、不创建采集任务、不启动 DMA 传输、不分配 RGB 或预览缓冲。结束后释放临时控制器和描述符、停止 MCLK，不切换共享复位和电源。USB U 盘模式跳过探测。结果仅保存在本次运行内存中，主页查询不会再次访问 I²C。

只有打开摄像头并请求画面时才重新检查 PID、配置传感器并分配 RGB 图像缓冲。两个 RGB565 缓冲共 1,228,800 字节，放在 PSRAM；显示画面为无压缩 4bpp 灰度，每份 153,600 字节，切换时最多保留当前和新画面两份。工作任务栈及 ISR 控制对象使用内部内存。首次采集丢弃 8 帧，后续丢弃 1 帧，采集超时 5 秒且支持退出取消。

两次取图之间停止 DMA、释放摄像头驱动的 PM 锁，保留传感器配置和 MCLK。退出、待机或采集失败会关闭会话，释放驱动及 RGB 缓冲；不关闭共享电源。

## 没有摄像头或 4G 的设备

默认固件允许两项功能，完整功能按需启动：

- 摄像头：开机探测未通过即隐藏主页入口；已通过探测但打开页面后不可用时显示提示，关闭自动预览，不反复初始化，点击拍照可手动重试。
- 4G：正常开机仅做 AT 硬件探测，未检测到则隐藏 4G/SIM 选项，并在本次运行中回到 Wi-Fi；只有检测成功且用户选择 4G 时才启动完整数据会话。无 SIM 或没有信号不隐藏设置入口，详见 [4G 数据通信](S31_CELLULAR_DATA.md)。
- 不将「未插 SIM / SIM 未就绪」当作「没有基带」，仍允许用户切换内置、外置 SIM。

可在 `menuconfig → MyPaperS31 optional hardware` 分别关闭：

```text
# CONFIG_MYPAPER_S31_CAMERA is not set
# CONFIG_MYPAPER_S31_CELLULAR is not set
```

关闭摄像头后不编译摄像头页面与采集实现，主页隐藏入口；关闭 4G 后不编译 NT26 实现，网络设置隐藏 4G 及 SIM 选项，忽略旧固件保存的 4G 偏好并使用 Wi-Fi。两项互相独立，不要求设备必须同时安装。

IDF 在读取 Kconfig 前扫描组件依赖，因此应用 CMake 的驱动依赖名保持声明，通过源文件条件编译及链接垃圾回收排除未启用功能；不会因声明驱动依赖而初始化硬件。

## 实机检查

1. 有摄像头：开机日志 `CAMERA_S31: boot probe` 显示 `present=1`，主页第二页出现摄像头；进入检查图像方向、灰度、自动预览及手动拍摄。本实现沿用官方 RGB565 字节序，实际模组仍需验证。
2. 无摄像头：日志显示 `present=0`，主页第二页不显示摄像头，也不能通过点击或按键选中隐藏入口；其余应用正常。USB U 盘模式不应出现摄像头探测日志。重新关机安装摄像头后开机应恢复入口。
3. 自动预览时返回、待机、唤醒，确认无 DMA 异常，PSRAM 在退出后恢复。
4. 同时安装 4G 和摄像头：分别使用功能，确认不因共享复位和电源影响触摸或网络。
5. 无基带：开机后网络设置隐藏 4G/SIM 选项；有基带无 SIM 时仍保留选项，选择 4G 后显示 SIM 状态而非隐藏入口。
6. 拍照：确认文件管理可打开 JPEG、电脑显示彩色 640×480；同一秒连拍不能覆盖旧照片。自动预览时目录不新增文件。
7. 无 SD 卡、写满、写入失败或保存中退出：确认失败提示与清理行为，不能留下误报成功的照片；再次进入可继续拍照。保存中待机后唤醒不能停留在保存状态。

传感器寄存器表来源与许可证随代码保留在 `main/boards/MyPaperS31/camera/`。新增界面字符串已同步更新系统字体子集；后续新增字符串仍需运行 `tools/subset_system_font.py` 并检查缺字。
