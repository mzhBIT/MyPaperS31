# 恢复默认设置

系统设置底部的“恢复默认设置”打开确认页，默认焦点为取消。用户明确选择“恢复并重启”后，清除配置并重启，使各模块的内存缓存重新采用默认值。

阅读默认值：刷新 Text（epd_text），图片开启。只修改默认值，不覆盖已有用户偏好；首次使用或者执行恢复后生效。RSS 独立配置也会恢复。

## 重置范围

- 系统语言、主页外框、前光、时区和时间显示格式。
- Wi-Fi 账号密码、网络选择及 Wi-Fi 电源策略。
- DeepSeek / 高德 Key、模型、地图来源及视图配置。
- 本地 / 微信阅读和 RSS 的排版、字体、背景、封面、自动翻页、动画、简繁转换及书籍阅读方向。
- 外放 / USB 输出选择与音量、来电铃声、中文键盘布局、微信阅读批注显示偏好。

采用配置命名空间白名单，不擦除整个 NVS 分区。旧 SD 阅读样式和字体配置文件也会移除，避免重新导入旧设置。文件删除或 NVS 提交失败时显示“恢复未完成，请重试”，不会报告成功或自动重启；部分配置可能已重置，可再次执行。

## 保留范围

书籍及原始文件、阅读进度和时长、聊天 / 短信 / 通话历史、股票自选列表、微信登录会话、触摸校准、地图包、字典、字体文件、缓存均不删除。不把恢复默认设置等同于清除所有用户数据。

## 真机验证

1. 更改语言、亮度、阅读样式、输出音量等配置。
2. 打开确认页后取消 / 返回，检查配置不变。
3. 确认恢复，检查自动重启及设置恢复默认；阅读刷新为 Text，图片开启。
4. 检查 Wi-Fi 需要重新配置、应用 Key 为空，书籍 / 进度 / 消息历史仍存在。
5. 再次重启，检查默认值持续生效，旧 SD 配置没有重新加载。
