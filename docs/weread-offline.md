# 微信读书离线阅读

## 入口与行为

- 打开微信读书自动尝试联网同步书架，不显示模式选择页。网络连接或书架同步失败时，有 SD 卡书架缓存就自动进入离线；没有缓存则显示错误。
- Cookie 过期时显示二维码登录页，二维码下方提供「离线阅读」按钮，不强制扫码。
- 默认联网加载页不显示「离线阅读」按钮，也没有隐藏的离线触摸区域；二维码登录和错误页面保留离线按钮。切换时先取消并等待网络任务安全退出，不强制删除任务。
- 联网失败且存在书架缓存时，先显示「联网失败，进入离线阅读模式」，在该提示扫描结束后停留约 1.5 秒，再自动显示离线书架；停留采用活动状态计时，返回操作仍可响应。
- 二维码生成失败或登录成功后书架请求失败，也可自动回退到已有缓存；用户取消返回不会自动跳入离线。
- 离线策略只作用于本次微信读书会话，退出应用后恢复；不写 NVS，不清除 Cookie，不更改其他应用网络配置。

## 离线范围

允许本地书架、目录、章节正文、已缓存评论、图片包及 EPUB 内容的读取。正文预取继续工作，但不得补下载章节、划线元数据、封面、图片包或评论，也不联网续期 Cookie/上传进度。

未缓存章节明确提示需要联网下载，不代表整本已经下载。未缓存评论提示离线不可用。阅读进度仍按现有退出保存流程保留本地待同步记录，下次联网同步再上报。

通过会话级原子策略统一约束 UI 工作任务、内容源及 HTTP 请求；模式切换只在旧工作任务返回最终结果后生效，避免客户端与队列生命周期冲突。

## 缓存书籍打开反馈

- 打开书架书籍时，已有目录缓存则直接提交一次 Text 白屏反馈，不再依次显示「正在加载章节」「正在下载章节」。
- 该白屏对象跨目录读取、续读位置选择、缓存章节检查和阅读器构造复用；缓存章节命中不再次提交白屏。
- 从目录直接打开缓存章节也采用同一白屏流程。未命中章节缓存时保留下载提示。
- 数据准备可与白屏扫描重叠，但阅读器首次绘制，以及错误、取消等状态绘制，必须先等待白屏结束再修改显示缓冲和模式。

## 验证

1. 联网同步并阅读一章，退出应用，关闭路由器重新进入：应自动回退离线并能打开缓存章节；正常联网时直接进入在线书架。
2. 有缓存时 Cookie 过期，选择联网进入二维码页后点击离线；无需扫码能回到书架。
3. 点击未缓存章节，应显示明确提示，返回能回到离线书架。
4. 已缓存评论可显示，缺失评论不请求；图片仅使用本地资源，网络日志不得出现新 HTTP 请求。
5. 离线退出保存进度，恢复网络重新进入，自动同步书架并上传待同步记录。
6. EN/简体/繁体分别验证入口、按钮及错误提示。
