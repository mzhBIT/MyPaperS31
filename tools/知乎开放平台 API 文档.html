一、Bearer 鉴权

所有数据接口统一使用 Authorization: Bearer <access_secret> 鉴权，同时要求 X-Request-Timestamp（秒级 Unix 时间戳）。

Header示例值说明
AuthorizationBearer <your_access_secret>Bearer 鉴权头
X-Request-Timestamp1742822400秒级 Unix 时间戳
Content-Typeapplication/jsonJSON 接口固定值

Access Secret 获取：知乎开放平台个人中心 登录后生成。

curl -G 'https://developer.zhihu.com/api/v1/content/zhihu_search' \
  --data-urlencode 'Query=怎么理解rave文化' \
  -H 'Authorization: Bearer <your_access_secret>' \
  -H "X-Request-Timestamp: $(date +%s)" \
  -H 'Content-Type: application/json'
本项目接入状态：已在 app.py 中封装统一鉴权（_zhihu_headers()），key 通过环境变量 ZHIHU_OPEN_API_KEY 或本地文件配置。

三、热榜 API GET

获取当前知乎热榜，返回结构化的标题、链接、缩略图与摘要。

https://developer.zhihu.com/api/v1/content/hot_list?Limit=30

Query 参数

名称类型必填说明
LimitInt32否返回数量，默认 30，最大 30

响应 Data

字段类型说明
TotalInt64实际返回的热榜条数
Items[].TitleString热榜标题
Items[].UrlString热榜对应的知乎链接
Items[].ThumbnailUrlString缩略图 URL，无封面时为空字符串
Items[].SummaryString内容摘要，无摘要时为空字符串
curl 'https://developer.zhihu.com/api/v1/content/hot_list?Limit=10' \
  -H 'Authorization: Bearer <your_access_secret>' \
  -H "X-Request-Timestamp: $(date +%s)"

本项目对接：GET /api/hotlist（每日缓存一次，返回 title/link/thumbnail/summary）。

四、知乎搜索 API GET

知乎站内内容搜索，返回与查询相关的问题、回答或文章。

https://developer.zhihu.com/api/v1/content/zhihu_search?Query=xxx&Count=10

Query 参数

名称类型必填说明
QueryString是查询关键词，不能为空
CountInt32否请求数量，默认 10，最大 10

响应 Data.Items[]

字段说明
Title内容标题
ContentType内容类型（Answer/Article 等）
ContentID内容标识
ContentText内容摘要，可能含 <em> 高亮标签
Url内容链接（带溯源 utm 参数）
CommentCount评论数
VoteUpCount赞同数
AuthorName作者昵称
EditTime发布时间或更新时间戳
RankingScore排序分数
curl -G 'https://developer.zhihu.com/api/v1/content/zhihu_search' \
  --data-urlencode 'Query=怎么理解rave文化' \
  -d 'Count=5' \
  -H 'Authorization: Bearer <your_access_secret>' \
  -H "X-Request-Timestamp: $(date +%s)"

本项目对接：GET /api/zhihu-search?query=xxx&count=10

五、全网搜索 API GET

全网内容搜索，用于补充新闻、官网及外部资料。

https://developer.zhihu.com/api/v1/content/global_search?Query=xxx&Count=20

Query 参数

名称类型必填说明
QueryString是查询关键词
CountInt32否请求数量，默认 10，最大 20
FilterString否高级筛选表达式（如 host=="example.com" AND publish_time>=1778494631），需 URL 编码
SearchDBString否索引库：all / realtime / static，默认 all

Filter 高级语法

  • host：站点域名，支持 ==、!=，如 host=="example.com"
  • publish_time：发布时间（秒级时间戳），支持 == != > >= < <=
  • 逻辑符：AND / OR 必须大写，AND 优先级高于 OR，可用括号控制
curl -G 'https://developer.zhihu.com/api/v1/content/global_search' \
  --data-urlencode 'Query=怎么理解rave文化' \
  --data-urlencode 'Filter=host=="example.com" AND publish_time>=1778494631' \
  -d 'Count=5' \
  -H 'Authorization: Bearer <your_access_secret>' \
  -H "X-Request-Timestamp: $(date +%s)"

本项目对接：GET /api/global-search?query=xxx&count=10&filter_expr=&search_db=all

六、直答 API POST

知乎直答，3 个模型档位：快速回答、深度思考、智能思考。

https://developer.zhihu.com/v1/chat/completions

Body 参数

名称类型必填说明
modelString是zhida-fast-1p5（快速）/ zhida-thinking-1p5（深度思考）/ zhida-agent（智能检索）
messagesArray是对话消息 [{role, content}]
streamBool否是否流式返回，默认 false

响应

{
  "model": "zhida-thinking-1p5",
  "choices": [{
    "message": {
      "role": "assistant",
      "reasoning_content": "先给出分析过程...",
      "content": "最终回答..."
    },
    "finish_reason": "stop"
  }]
}

本项目对接：POST /api/zhida，body {"query": "问题", "model": "zhida-fast-1p5"}

七、我的创作 API GET

获取当前账号公开范围内的创作内容（回答/文章/视频/想法/问题），无需 OAuth。

https://developer.zhihu.com/api/v1/user/contents?ContentType=all&Limit=20

Query 参数

名称类型必填说明
ContentTypeString是all / answer / article / zvideo / pin / question
OffsetInt64否分页偏移量，默认 0
LimitInt64否返回数量，默认 20，最大 50
SortFieldString否like_count / ts，默认 ts
SortOrderString否asc / desc，默认 desc

响应 Data.Items[]

字段说明
ContentType内容类型
Url内容链接
Title内容标题
Summary内容摘要
LikeCount / CommentCount / FavoriteCount点赞 / 评论 / 收藏数
CreatedAt创建时间（秒级时间戳）
curl -G 'https://developer.zhihu.com/api/v1/user/contents' \
  -d 'ContentType=all' -d 'Limit=20' \
  -H 'Authorization: Bearer <your_access_secret>' \
  -H "X-Request-Timestamp: $(date +%s)"

本项目对接：GET /api/my-contents?content_type=all&limit=20（可追踪发布后的数据表现）

八、关注 / 收藏 API

接口URL说明
用户关注/api/v1/user/followees关注列表（Limit 默认 20，最大 50）
用户收藏/api/v1/user/collections近期收藏内容
收藏夹列表/api/v1/user/favlists收藏夹列表
收藏夹内容/api/v1/user/favlist_contents指定收藏夹内容（需 FavlistUrlToken）

以上接口均支持 X-OAuth-Token 查询已授权用户数据；不传则查询本人。

九、PDF 解析 API（异步）

三步调用：上传文件 → 创建任务 → 轮询状态。

步骤URL方法说明
1. 上传文件/resources/v1/filesPOSTmultipart/form-data，file 字段，最大 100MB
2. 创建任务/api/v1/pdf-parse/tasksPOSTbody: {"file_id": "..."}
3. 查询任务/api/v1/pdf-parse/tasks/{task_id}GETtask_status: pending/running/succeeded/failed

任务成功时 result.url 为解析结果下载链接（JSON 格式，含 pages/blocks）。

十、PPT 生成 API（异步）

根据知乎回答/文章链接异步生成 PPT。

步骤URL方法说明
1. 创建任务/api/v1/ppt-generation/tasksPOSTbody: {"resource_url": "...", "num_pages": 12}（页数 6-21）
2. 查询任务/api/v1/ppt-generation/tasks/{task_id}GET成功时 result.url 为 PPTX 下载链接

支持链接：知乎回答、知乎专栏文章。
