准备与连接

  1. 使用可传输数据的 USB 线连接设备，关闭串口监视器。
  2. 点击连接，选择阅读器对应的 USB 串口。
  3. 连接失败时按住 BOOT，短按 RESET，再松开 BOOT 重试。

操作日志

    
常见问题
找不到串口？
检查 USB 数据线、USB 转接器及系统驱动；确保串口未被 VS Code 或其他软件占用。
刷机时断开了？
换短数据线，降低速率后重新烧录。写入失败不会显示成功，也不会自动重启。
完成后没有重启？
如果已提示写入和校验成功，松开 BOOT 后按 RESET 或重新上电即可。
